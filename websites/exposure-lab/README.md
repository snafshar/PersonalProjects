# Exposure Lab

**[Live website](https://exposure-lab.afsharsn.chatgpt.site)**

I designed and implemented Exposure Lab as an interactive photography tool. It helps photographers understand the trade-offs between aperture, shutter speed, ISO, and focal length before taking a photograph.

## What I built

- Live exposure-value calculation
- Aperture, shutter, ISO, and focal-length controls
- Handheld shutter-speed guidance
- Portrait, street, landscape, and action presets
- Responsive, accessible interface

## Technology

React, TypeScript, CSS, Next.js-compatible routing, and Vinext for Cloudflare deployment.

## Run locally

```bash
npm install
npm run dev
```

The calculator is an educational estimator. A production version would add camera-specific sensor data, depth-of-field calculations, and persistent presets.
